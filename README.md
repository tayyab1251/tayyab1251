### 📖 Prologue

> In a world running on semicolons and stack traces, a young developer picked up **PHP** — not because it was easy, but because he wanted to know what was happening *underneath* the magic. Somewhere between broken migrations and 2am debugging sessions, he stopped just writing code that worked, and started asking code to make *sense*.
>
> This is that story. Still being written, one commit at a time.

### 📜 Chapters

<details>
<summary><b>Chapter I — The Fundamentals</b> · <i>where it all began</i></summary>
<br>

Before frameworks, before shortcuts — just **PHP, MySQL, and a lot of trial & error**. Requests, forms, sessions, raw queries. Learning what a framework quietly does for you, by first doing it the hard way.

</details>

<details>
<summary><b>Chapter II — The First Real Battle</b> · <i>the internship</i></summary>
<br>

Tutorials don't prepare you for a real codebase. An internship threw him into an actual production project — bugs with consequences, code other people depended on. This is where "it works on my machine" stopped being an acceptable ending.

</details>

<details>
<summary><b>Chapter III — Into the Guild</b> · <i>the travel-tech era</i></summary>
<br>

Joined a **travel-product company**, working inside an existing product with real users. Learned the unglamorous, important stuff: integrations, APIs, databases under load, and solving problems with no answer key.

</details>

<details>
<summary><b>Chapter IV — The Laravel Arc</b> · <i>current chapter</i></summary>
<br>

When the path shifted, so did the focus. Not just "add Laravel to the CV" — but genuinely go deeper: architecture, middleware, auth, Sanctum, clean structure. The framework changed; the obsession with *understanding* didn't.

</details>
